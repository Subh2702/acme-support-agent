# Deploying

There was no authenticated hosting CLI in the build environment (no `render` or `gh` CLI, and Docker wasn't running), so nothing was deployed automatically. These steps take about 15 minutes.

> **Why a hosted LLM on Render:** Render instances have no GPU and too little RAM to run a local model, so the public demo uses the Hugging Face router (or Anthropic) instead of Ollama. The daily ₹ budget cap (`DAILY_BUDGET_INR`) protects that key.

## 0. Prerequisites (2 min)
- A GitHub account and a Render account (https://dashboard.render.com, sign in with GitHub).
- An LLM credential with credits. Either:
  - a **Hugging Face token** with Inference Providers credits (https://huggingface.co/settings/tokens → "Make calls to Inference Providers"; add credits under Billing). The free tier's monthly allowance is very small. Or:
  - an **Anthropic API key** (https://console.anthropic.com).

## 1. Push the repository to GitHub (3 min)
```bash
cd /path/to/Project1
git remote add origin https://github.com/<you>/acme-support-agent.git
git push -u origin main
```
GitHub Actions (`.github/workflows/ci.yml`) starts automatically: lint, tests with the coverage gate, Docker build + boot probe, and a smoke eval against a 0.5B model on the runner. Check the **Actions** tab.

## 2. Create the Blueprint on Render (5 min)
1. Render dashboard → **New +** → **Blueprint**.
2. Connect the GitHub repo and select it. Render reads `render.yaml` and shows two resources:
   - `acme-support-agent`: a Docker web service in **Singapore**, `starter` plan.
   - `acme-db`: Postgres in **Singapore**, `basic-256mb`.
3. Fill the variables marked **sync: false**:
   - `HF_TOKEN`: your Hugging Face token. Leave empty if you use Anthropic.
   - `LLM_API_KEY`: your Anthropic key. Leave empty if you use Hugging Face.
4. If you use Anthropic, open the web service's **Environment** tab after creation and change `LLM_PROVIDER` to `anthropic`.
5. Click **Apply**. The first build takes about 6–10 minutes: the image installs chromadb/onnxruntime and bakes in the embedding model.

`ADMIN_PASSWORD` and `IP_HASH_SALT` are generated by Render. To read them, open the web service → **Environment** → reveal `ADMIN_PASSWORD`.

## 3. Verify (2 min)
```bash
URL=https://acme-support-agent.onrender.com      # your service URL
curl -fs $URL/healthz                             # {"status":"ok"}
curl -fs $URL/readyz                              # database ok, knowledge_base ok
curl -fs $URL/api/demo-info | head -c 300          # model + demo credentials
curl -fsN -X POST $URL/api/chat/stream -H 'content-type: application/json' \
  -d '{"message":"What is your return window?"}'
```
Then open `$URL/` for the chat and `$URL/admin` (user `admin`, the generated password).

On the first boot the database is seeded automatically (40 customers, 150 orders). To refresh the date-relative edge cases later (for example "delivered 29 days ago"), use **Admin → Overview → Reset demo data**.

## 4. Recommended settings for a public demo
| Variable | Suggested | Why |
|---|---|---|
| `DAILY_BUDGET_INR` | `100` | Hard daily cap on LLM spend; the chat shows "demo limit reached" when it's hit |
| `RATE_LIMIT_IP_PER_MIN` | `20` | Per-IP flood protection |
| `RATE_LIMIT_SESSION_PER_MIN` | `10` | Per-conversation flood protection |
| `HF_MODEL` | `Qwen/Qwen3-235B-A22B-Instruct-2507:cheapest` | Strong tool use; `:cheapest` picks the lowest-price provider |

## Alternative: run everything locally with Docker
```bash
cp .env.example .env              # set ADMIN_PASSWORD (and HF_TOKEN / LLM_API_KEY if you want)
# Option A — use the Ollama already running on your machine (must listen on all interfaces):
OLLAMA_HOST=0.0.0.0 ollama serve &   # then:
docker compose up --build
# Option B — run Ollama in a container too (downloads ~2.5 GB of weights once):
OLLAMA_BASE_URL=http://ollama:11434 docker compose --profile ollama up --build
```
Open http://localhost:8000 (chat) and http://localhost:8000/admin.

## Troubleshooting
| Symptom | Fix |
|---|---|
| Chat replies "isn't connected to its language model" | No LLM credentials: set `HF_TOKEN` or `LLM_API_KEY` (or make Ollama reachable) |
| Hugging Face 402 in logs | Credits exhausted; add credits or switch provider |
| `/readyz` 503 with `knowledge_base: building` | Wait for the first index build (seconds) |
| `/admin` returns 503 | `ADMIN_PASSWORD` is empty |
| Out-of-memory on Render | Use the `starter` plan or larger (Chroma + ONNX need more than 512 MB headroom) |

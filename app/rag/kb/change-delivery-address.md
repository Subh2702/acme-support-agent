# Changing your delivery address

## Before dispatch
You can change the delivery address of an order while it is still "processing" (before it ships). Share the new address with a 6-digit PIN code and, if you like, a new contact number. If the new PIN code is not serviceable we will let you know.

## After dispatch
Once an order has shipped, we cannot change the address in our system. You can use the courier's own options from the tracking SMS (reschedule, redirect to a nearby pickup point where available) or refuse the delivery and place a new order.

## Address format tips
Include your flat or house number, building, street, area or landmark, city, state and PIN code. A correct PIN code is the single most important detail for fast delivery.

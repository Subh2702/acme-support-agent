# Size exchanges

## Exchange policy
Footwear and apparel can be exchanged once per order for a different size within 30 days of delivery, if the new size is in stock. The item must be unused with tags attached.

## How it works
Request the exchange with your order number and the size you need. We pick up the original item and ship the new size at no extra cost. If the size is out of stock, you can return the item for a refund instead.

## Size help
Every product page has a size chart. Trekking shoes run true to Indian/UK sizing; if you are between sizes or will wear thick trekking socks, choose the larger size.
